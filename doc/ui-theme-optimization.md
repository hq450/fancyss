## 主题色方案

### ROG (红黑色)
- 主色: `#ff4646` (红色)
- 高亮: `rgba(255,70,70,0.42)`
- 背景: 深黑色调
- 保持原有的红色科技感

### ASUSWRT (蓝灰色)
- 主色: `#3b82f6` (蓝色)
- 高亮: `rgba(59,130,246,0.42)`
- 背景: 深蓝灰色调
- 专业稳重的商务风格

### TUF (橙黑色)
- 主色: `#fb923c` (橙色)
- 高亮: `rgba(251,146,60,0.42)`
- 背景: 深橙黑色调

### TS (青色)
- 主色: `#22d3ee` (青色)
- 高亮: `rgba(34,211,238,0.42)`
- 背景: 深青黑色调
- 现代科技感的青色主题

## 实现方式

使用 CSS 属性选择器 `body[skin="XXX"]` 针对不同皮肤应用特定样式：

```css
/* 示例：ROG 皮肤的节点卡片 */
body[skin="ROG"] .node-card {
    border-color: rgba(74,108,138,0.22);
    background: linear-gradient(180deg,rgba(18,25,36,0.98),rgba(12,18,27,0.96));
}
body[skin="ROG"] .node-card:hover {
    border-color: rgba(255,70,70,0.42);
}
```
